# netw

Personal net worth tracker.

- Add assets and liabilities as line items; the app totals them automatically.
- Save a snapshot any time to build a history of your net worth over time, shown as a chart and a list of movements between snapshots.
- Export your data to a CSV file for backup, or import a CSV to restore it — useful for keeping a copy in iCloud Drive or moving between devices.

## How it stores data

All data lives in your browser's local storage on whatever device you're using — nothing is saved to this repo or to any server. The CSV export/import is a manual backup you trigger yourself; it isn't a live sync.

## Usage

Open the GitHub Pages URL for this repo in Safari, then Share → Add to Home Screen for a full-screen app icon.

## Privacy

This repo contains no personal data. It's a single, dependency-free HTML file with no financial information baked in — every account name and balance you enter stays local to your device unless you explicitly export it.
